# Sandesh Kumar — DevOps Portfolio

Responsive professional-light portfolio made with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP and open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.

## Personalize before publishing
- Replace `ADD-YOUR-EMAIL@example.com` in `index.html` with your email.
- Replace the LinkedIn placeholder with your actual LinkedIn profile URL.
- Check the certificate titles against the exact wording printed on your certificates.
- Ensure the included PDF resume is your latest copy.
- Update skills and project details as your experience changes.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder; keep `index.html` at the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section.
